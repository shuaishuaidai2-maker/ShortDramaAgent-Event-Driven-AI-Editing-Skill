# 剪辑节奏范例

## 案例："你为什么骗我？"

### 原始（普通剪辑，全部保留）
```
女主："你为什么骗我？"
男主沉默。
女主看着他。
男主低头。
男主："因为……你爸是我杀的。"
```

### 短剧版（节奏化）
```
女主："你为什么骗我？"  CUT
男主眼神 0.5s
女主特写 0.7s
男主："因为……"      音乐骤停
0.25s 黑/静音
男主："你爸是我杀的。" IMPACT
```

### 节奏要点
- 台词说完立刻 CUT，不给拖尾
- 用反应镜头（眼神/特写）填充停顿，而不是留空镜
- 反转台词前 0.25s 黑屏 + 静音，制造冲击
- 爆点台词落在 IMPACT 音效上

## 案例："其实公司已经破产了"

### 原始开头（掉留存）
```
00:00 女主进公司
00:08 同事聊天
00:20 老板出现
00:35 老板说："其实公司已经破产了。"
```

### 短剧版（结果前置 + 回闪）
```
00:00 老板："其实公司已经破产了。"  CUT
00:03 字幕："三小时前"
00:05 女主进公司（回到正常叙事）
```

### 原则
- 开头直接给最抓人的信息（强冲突/强情绪/悬念/身份反转/结果前置/危险/羞辱/抓奸/争吵/威胁/秘密）
- 用"字幕回闪"结构承接，而不是平铺直叙

## 案例："那个孩子其实不是你的"

### 普通逻辑（一直拍 A 说话）
```
A："那个孩子其实不是你的。"
```

### 短剧逻辑（插入反应镜头）
```
A 说前半句："那个孩子其实……"
B 反应特写
A："不是你的。"
B 震惊
IMPACT
```

### 原则
- 优先剪接收信息的人的反应
- 信息句拆成两半，中间插反应，后半句落在震惊上
